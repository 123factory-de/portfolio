## Company Overview

MOBILWITHUS develops embedded security software for vehicles and connected control systems. The company focuses on ECU software, SDV security, automotive semiconductor security, and regulatory cybersecurity needs.

Its work is relevant as vehicles, batteries, and industrial equipment become more software-defined. OEMs and Tier suppliers need secure boot, secure updates, key management, diagnostics, and compliance evidence across many controllers.

## Technology & Product

[MOBIL Sherpa+](https://mobilwithus-e.imweb.me/automotive-ECU-software) is an automotive embedded security complex device driver. It helps OEMs and Tier suppliers integrate HSM and HSE functions into ECUs.

The product supports AUTOSAR CDD, AUTOSAR and non-AUTOSAR interfaces, MCAL, and hardware abstraction. It covers Secure Boot, Secure Communication, Secure Access, Secure Authentication, Secure Storage, Secure Debug, Secure Software Update, and Secure Key Management.

MOBILWITHUS also provides engineering, test, and consulting services for security requirements, UDS diagnostics, FBL, AUTOSAR application CDD, legacy software, and secure coding review.

## Market & Use Cases

The main users are automotive OEMs, Tier suppliers, semiconductor teams, ESS BMS makers, and heavy-equipment manufacturers. The product is useful where software controllers must meet cybersecurity regulations and buyer security requirements.

Use cases include UN ECE R155 and R156 response, Cyber Resilience Act preparation, secure ECU integration, controller-level security tests, and production software validation.

## Traction & References

MOBIL Sherpa+ has been validated across more than four global OEM programs and more than eleven ECU projects.

The supported semiconductor lineup includes NXP S32K1XX/S32K3XX, Infineon TC3XX, and Microchip SAME5X/SAMC2X/TA100. MOBILWITHUS also applied and supplied CRA security functions for an ESS BMS project in 2026.

The company has joined IBK Changgong programs, including Germany and Luxembourg-linked scale-up tracks.
