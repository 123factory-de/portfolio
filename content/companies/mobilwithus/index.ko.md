## 회사 개요

모빌위더스는 차량과 연결형 제어 시스템을 위한 임베디드 보안 소프트웨어를 개발합니다. ECU 소프트웨어, SDV 보안, 차량 반도체 보안, 사이버보안 규제 대응이 핵심 영역입니다.

차량, 배터리, 산업 장비가 소프트웨어 중심으로 바뀌면서 컨트롤러 단위의 보안 요구가 커지고 있습니다. OEM과 Tier는 Secure Boot, Secure Update, 키 관리, 진단, 규제 대응 증빙을 함께 준비해야 합니다.

## 기술 및 제품

[MOBIL Sherpa+](https://mobilwithus-e.imweb.me/automotive-ECU-software)는 차량용 임베디드 보안 Complex Device Driver입니다. OEM과 Tier가 ECU에 HSM, HSE 기능을 통합하도록 돕습니다.

AUTOSAR CDD, AUTOSAR 및 non-AUTOSAR 인터페이스, MCAL, Hardware Abstraction을 지원합니다. Secure Boot, Secure Communication, Secure Access, Secure Authentication, Secure Storage, Secure Debug, Secure Software Update, Secure Key Management 기능을 다룹니다.

보안 요구사항 분석, UDS 진단, FBL, AUTOSAR Application CDD, 레거시 소프트웨어, Secure Coding 검토를 포함한 엔지니어링과 테스트 서비스도 제공합니다.

## 시장 및 활용 분야

주요 고객은 자동차 OEM, Tier 공급사, 반도체 팀, ESS BMS 제조사, 중장비 제조사입니다. 소프트웨어 컨트롤러가 사이버보안 규제와 구매사 보안 요구를 충족해야 하는 환경에 적합합니다.

UN ECE R155/R156 대응, Cyber Resilience Act 준비, ECU 보안 통합, 컨트롤러 보안 테스트, 양산 소프트웨어 검증에 활용할 수 있습니다.

## 성과 및 레퍼런스

MOBIL Sherpa+는 회사 제품 페이지에서 글로벌 OEM 4곳 이상, ECU 11개 이상 프로젝트 검증 이력을 제시합니다.

지원 반도체 라인업에는 NXP S32K1XX/S32K3XX, Infineon TC3XX, Microchip SAME5X/SAMC2X/TA100이 포함됩니다. 2026년에는 ESS BMS 프로젝트에 CRA 대응 보안 기능을 적용하고 공급했습니다.

IBK창공 프로그램에도 참여했으며, 독일과 룩셈부르크 연계 스케일업 트랙 이력이 있습니다.

## 협업 가능성

OEM, Tier 공급사, 반도체 기업, ESS 제조사, 산업 장비 기업과 협업할 수 있습니다. 특정 컨트롤러를 대상으로 Secure Boot, Secure Update, 키 관리, 사이버보안 규제 증빙을 검증하는 PoC가 적합합니다.

한국과 유럽 협업에서는 유럽 차량 사이버보안 규제, CRA 대응, 협력사 소프트웨어 보안 검증과 잘 맞습니다.
