## Company Overview

SSenStone develops authentication technology for users, devices, IoT, PLC, and OT/ICS environments. Its core technology is OTAC, a one-time dynamic authentication code.

The company addresses a common security issue: fixed passwords and static credentials are hard to protect across many devices and industrial systems. OTAC replaces static values with changing codes that can be verified without the same one-time code being reused.

## Technology & Product

[OTAC](https://www.ssenstone.com/tech/tech-otac) is SSenStone's core one-way dynamic authentication technology. It supports authentication between people, devices, and control systems.

[Endpoint OTAC](https://www.ssenstone.com/en/solution/endpoint-otac) applies the technology to ICS and OT environments. It helps restrict PLC access to approved users and devices, and supports security work linked to NIS2, CRA, NERC CIP, and IEC 62443.

Other product areas include TAP OTAC for card-tap authentication, IoT Auth Platform OTAC, and HomeNet OTAC.

## Market & Use Cases

SSenStone is relevant for industrial sites, OT operators, IoT device makers, financial institutions, access-control systems, and smart-home environments.

Use cases include PLC access control, device authentication, phishing-resistant authentication, industrial remote access, and dynamic credential replacement for connected devices.
